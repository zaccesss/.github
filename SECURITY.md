# Security Policy

> [!IMPORTANT]
> Please report a security problem privately. Use **Report a vulnerability** on the repository's **Security** tab (`https://github.com/zaccesss/<repo>/security/advisories/new`) or email contact@isaacadjei.me. Do not open a public issue or pull request. If the repository has its own security policy, follow that.

The full policy, covering the scope, the disclosure process and the expected response times, is in [zaccesss/security-policy](https://github.com/zaccesss/security-policy) and on [my site](https://isaacadjei.me/security-policy).
