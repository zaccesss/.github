# .github

Default community-health files for my GitHub account. GitHub falls back to the files here for any of my repositories that does not carry its own copy, so I keep one consistent set in one place.

## What is here

- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) - how I expect interactions to go.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) - how to flag something or propose a change.
- [`SECURITY.md`](SECURITY.md) - how to report a security issue privately.
- [`SUPPORT.md`](SUPPORT.md) - where to go for help.
- [`ACCESSIBILITY.md`](ACCESSIBILITY.md) - how the documentation is written to be accessible and how to report a barrier.
- [`.github/FUNDING.yml`](.github/FUNDING.yml) - the sponsor links.
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) and [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) - the default issue and pull request templates.
- [`CHANGELOG.md`](CHANGELOG.md) - what changed here and when.

A repository with its own version of any of these overrides the default here.

## Notes

- My GitHub profile page is driven by my [`zaccesss`](https://github.com/zaccesss/zaccesss) repository, not this one.
- Some files that GitHub does not inherit org-wide, like `CODEOWNERS` and `dependabot.yml`, are applied per repository instead.
