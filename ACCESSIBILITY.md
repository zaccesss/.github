# Accessibility

This applies to every repository here that does not have its own `ACCESSIBILITY.md`. A repository with settings of its own, such as colours or key bindings, documents them in its own file, which takes precedence.

## Documentation

Documentation here aims to:

- Use a real heading outline, so screen readers and the page outline can jump between sections.
- Use link text that says where the link goes, never "click here".
- Give images and badges alt text.
- Write diagrams as Mermaid or tables where possible, so their content is text.
- Show code, commands and output as text, never as screenshots.
- Never rely on colour alone: callouts carry a label such as Note, Tip or Warning.
- Use plain language, explaining a term where it first appears.

## Reporting a barrier

If anything in a repository is hard to read or use, open an issue there describing what happened and what would help. Accessibility problems are treated as bugs.

For anything private, use [isaacadjei.me/contact](https://isaacadjei.me/contact).
